# src/utils/

Small shared helpers. Each file has one job.

| File                                | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| :---------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `durable.ts`                        | The ONE disk writer (`writeFileDurable`: temp, fsync, `.bak`, rename, folder fsync), `readWithBackup`, `lockFolder` (one process per folder, used for session folders; stale-lock takeover, temp sweep) and `withFileMutex` (short per-file lock for state several processes change, e.g. one scheduled action).                                                                                                                                                             |
| `home.ts`                           | `resolveHome` / `setHome`: the single folder everything is stored in.                                                                                                                                                                                                                                                                                                                                                                                                        |
| `env.ts`                            | Process-env lookups and API key resolution. No `globalThis` fallback.                                                                                                                                                                                                                                                                                                                                                                                                        |
| `headers.ts`                        | Session-affinity headers, opt-in attribution, browser stripping, package version fallback.                                                                                                                                                                                                                                                                                                                                                                                   |
| `media.ts`                          | Normalizes a path, URL, data URL, base64 or bytes to base64 and a MIME type; magic-byte sniffing.                                                                                                                                                                                                                                                                                                                                                                            |
| `safe-io.ts`                        | `fileAccess.roots` containment and the guarded remote fetch (private hosts refused, redirects re-checked, size cap).                                                                                                                                                                                                                                                                                                                                                         |
| `raw-capture.ts`                    | The `captureRaw` policy for `AgentResponse.raw`.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `cache.ts`                          | Cache-key clamp (64 chars) and the central secret redaction.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `errors.ts`                         | `toConciseProviderError` (any raw provider failure becomes one-line `ProviderError`: `code` `"provider"`, `retryable` from status/code, the provider's code as `providerCode`; SDK errors pass through), `isTransientError`, `markRetryable`, and the small readers the error code shares (`dig`, `displayModel`). The pre-network modality guards moved to `providers/modalities.ts`: `utils/` imports only from `utils/` and `types/` (`test/layering.test.ts` checks it). |
| `retry.ts`                          | `withRetries`, `isTransientError` (re-exported from `errors.ts`), `isRetryableRun`, `sleep`. Structured data only (status, code, flags), never message text.                                                                                                                                                                                                                                                                                                                 |
| `session.ts`                        | Id helpers (`createSessionId`, `hashSessionPart`, `createTrackingId`, run/turn ids), `previewPrompt`.                                                                                                                                                                                                                                                                                                                                                                        |
| `provider-call.ts`                  | What the one-call functions (`generateImage`, `generateEmbedding`, `generateDecision`) share: `bounded` (timeout and abort around one provider request), `addUsage`, `ConnectionOptions`, `providerOptionsFrom` and `readInputPart` (reads one text or media part for an embedding or a decision).                                                                                                                                                                           |
| `mp4.ts`                            | `mp4DurationSeconds`: the length of an MP4 or MOV file from its `moov/mvhd` header (no decoding); anything else is `undefined`.                                                                                                                                                                                                                                                                                                                                              |
| `serialization.ts`                  | `toJsonSafe`, `safeStringify`.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `base64.ts`, `thought-signature.ts` | Runtime-agnostic base64; Gemini thought-signature helpers.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `body.ts`                           | `readTextCapped` / `readBytesCapped`: read a response body with a byte cap (chat 64 MB, bulk replies 256 MB, error bodies 1 MB, downloads 512 MB), cancelling the connection at the cap; over it is a non-retryable `ProviderError`.                                                                                                                                                                                                                                         |
| `guards.ts`, `text.ts`, `noop.ts`   | `isRecord` (the one plain-object guard), `beforeFirst` (text before a separator), `noop` (a named do-nothing callback, for `promise.catch(noop)`).                                                                                                                                                                                                                                                                                                                           |
| `media-part.ts`                     | Typed access to a media part: `MEDIA_KEYS`, `mediaKeyOf` (safe on untrusted data), `mediaValueOf`, `makeMediaPart`. Replaces casts that reached the payload by key.                                                                                                                                                                                                                                                                                                          |

## Invariants

- Never write state with a bare `writeFileSync`; use `writeFileDurable`.
- `media.ts` and `safe-io.ts` import `node:*` lazily so browser bundles keep working.
- Redaction is central (`cache.ts`); adapters must not keep their own deny-lists.
- The home is set in code only (`setHome()` or an Agent's `home`; there is no env var). `setHome()` after import relies on the catalog reload hook.
- The environment is read for API keys only (`env.ts`); every other option is a setting (`config/settings.ts`).
- A response body is never read whole without a cap (`body.ts`), and every empty `catch` says why it is empty.
