## Contract (`Provider`, in `../types/model.ts`)

`generate(model, context, options)` returns a `ProviderGenerateResult`; `stream(...)` returns an `AssistantMessageEventStream` that ends with an `AgentResponse`; optional `isLongRunning()` tells the loop to skip its whole-call timeouts; optional `generateImage(modelId, request, options)` makes pictures for the providers with supported image models (the request is already checked by `image/request.ts`); optional `embed(modelId, request, options)` makes one vector per item for the providers with supported embedding models (the request is already checked by `embedding/request.ts` and holds no more items than the model takes in one request); optional `decide(modelId, request, options)` answers the typed questions of a decision request with one answer per question (the request is already checked by `decision/request.ts`); optional `generateVideo(modelId, request, options)` makes one video for the providers with supported video models (the request is already checked by `video/request.ts`; a provider that works in jobs submits, polls with `video/poll.ts::pollJob` within `request.deadlineMs` and downloads inside this one call).

## Invariants

- Fix shared streaming behaviour in `shared.ts`, never per adapter. Event parsing and request building stay in each adapter.
- OpenRouter and compat chat chunk handlers are deliberately not merged.
- A custom prefix never gets another provider's key or base URL.
- A transient failure is retried only before the first byte of a stream. An adapter may mark an error `transient: false` (Anthropic's spend-cap 429): `isTransientError` honours it over the status rules.
- A stream that ends without a terminal event while a tool call is missing or cut fails as a retryable `incomplete_stream`.
- A non-streaming HTTP 200 whose body is not a reply (`{}`, a list, `null`, no `choices`, no `output` or `content` list) is never read as an empty answer: the adapter runs its `reply-guard.ts` check before the cast and throws a retryable `ProviderError` (status 502). A legitimately empty answer (an empty `output` or `content` list, empty text) is still an answer.
- Adapters cancel a reader with `reader.cancel().catch(() => {})`, never a bare `void reader.cancel()`.
- To add a provider: implement `Provider` on native `fetch`, reuse `shared.ts`, add pure mappers to `../providers.ts`, register in `registry.ts`.
- No adapter reads a whole response body without a cap: `utils/body.ts` stops and cancels the connection at 64 MB (chat replies), 256 MB (images, vectors, decisions, video jobs), 1 MB (error bodies) and 512 MB (downloads). Over the cap is a non-retryable `ProviderError`.
