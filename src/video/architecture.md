# src/video/

Video generation: `generateVideo` and its pieces. The supported models and their facts are in `../models/video-models.ts` (Google by hand) and `../models/openrouter-videos.ts` (OpenRouter's own list, cached); the wire code of each provider is in `../providers/<provider>.ts` (`Provider.generateVideo`).

| File          | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| :------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `request.ts`  | `resolveVideoRequest`: checks a `VideoOptions` against the model's entry (length, tier, ratio, exact size, frame roles, reference picture and clip counts, audio, seed), spells the tier as the model lists it and returns the final request plus warnings. Pure. One `ValidationError` lists every problem.                                                                                                                                       |
| `generate.ts` | `generateVideo`: makes sure OpenRouter's list is loaded (for `openrouter/...`), model lookup (`ConfigError` with the reason), `setModels` check, request check, warnings on the bus, a pre-call cost estimate against `budget` (Google), media read (`fileAccess`) and the reference clip length check, ONE provider request under `withProviderSlot` (abortable; the deadline is the adapter's), a check that a video came back, pricing, budget. |
| `poll.ts`     | `pollJob`: the one poll loop of every provider that works in jobs: first poll at once, `onProgress`, deadline (`TimeoutError`), abort (`AbortError`); every error that leaves it carries the job's id (`error.jobId`, not enumerable).                                                                                                                                                                                                             |
| `pricing.ts`  | `priceVideoUsage` (token prices of the table, integer micro-USD; `undefined` when it cannot be priced exactly) and `estimateVideoCostUsd` (seconds times the table's tokens per second).                                                                                                                                                                                                                                                           |
| `result.ts`   | `GeneratedVideo` (bytes, `save`, `toPart`, `durationSeconds` from the MP4 header, small `toJSON`) and `VideoResult`.                                                                                                                                                                                                                                                                                                                               |

## Invariants

- A value outside a model's list is a problem (one `ValidationError` for all of them); a control the model does not have (`seed`, `size`, a switch for audio) is a warning and is dropped. Pictures and clips are content: a frame role a model lacks is an error, never a silent text-to-video.
- The adapter receives a checked request (`ProviderVideoRequest`) with its pictures and clips read; it never validates options itself, and it enforces `deadlineMs` through `pollJob` so the error can carry the job id.
- A job at the provider is NOT cancelled by a timeout or an abort (OpenRouter has no cancel): the error carries `jobId` so the caller can look it up. The `concurrency` slot is held until the call ends.
- A call that returns has a non-empty video; a reply with only words (a refusal) is a non-retryable `ProviderError` that carries them.
- Clip lengths are read from MP4 and MOV headers only (`utils/mp4.ts`); any other container is left to the provider. A clip may exceed a limit by 0.25 s (encoders round up).
- Cost: the provider's reported cost wins, else the table prices the reported tokens, else it is unknown (never 0). A pre-call estimate exists only for models with a token price table.
- `VideoResult` and `GeneratedVideo` never put the bytes in JSON.
