# src/embedding/

Embeddings: `generateEmbedding` and its pieces. The supported models and their facts are in `../models/embedding-models.ts` (Google and OpenAI by hand) and `../models/openrouter-embeddings.ts` (OpenRouter's own list, cached); the wire code of each provider is in `../providers/<provider>.ts` (`Provider.embed`).

| File            | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| :-------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `request.ts`    | `resolveEmbeddingRequest`: checks an `EmbeddingOptions` against the model's entry (input kinds, per-vector image and PDF limits, `dimensions`, `task`, `title`), turns every item into a list of parts, and returns the final request plus warnings. Pure.                                                                                                                                                                                                                                                  |
| `generate.ts`   | `generateEmbedding`: makes sure OpenRouter's list is loaded (for `openrouter/...`), looks the model up (`ConfigError` with the reason), `setModels` check, request check, warnings on the bus, media read (`fileAccess`, type check), the list cut into the model's request size (`maxInputs`, else 100) and run four at a time (each under `withProviderSlot`, timeout and abort bounded), reply checks, pricing, budget, re-normalizing of shortened vectors for the models that need it, usage added up. |
| `pricing.ts`    | `priceEmbeddingUsage`: the table's price in integer micro-USD, per kind of input when the provider splits the tokens; `undefined` when it cannot be priced exactly.                                                                                                                                                                                                                                                                                                                                         |
| `result.ts`     | `EmbeddingResult`: `vectors`, `vector`, `dimensions`, `usage`, `raw`, `requests`.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `similarity.ts` | `cosineSimilarity`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Invariants

- A list in gives one vector per item out, in order, on every model. The adapter receives items, each already a list of parts that make ONE vector, and never more than the model takes in one request; it returns exactly one vector per item.
- A value outside a model's limits is a problem (one `ValidationError` for all of them); a control the model does not have (`task` on OpenAI, a `title` outside Google) is a warning and is dropped. Nothing is guessed and nothing is silently changed. Token counts are not checked: the provider says when an input is too long.
- Every reply is checked (count, finite non-empty numbers, one length) before it is used; an unusable one is a non-retryable `ProviderError`.
- Cost: the provider's reported cost wins, else the table prices the reported tokens (per kind when split), else it is unknown (never 0, never a partial sum).
- A failure stops the other requests; vectors that finished are on `error.partial.vectors`, aligned with the input.
- Vectors of different models or lengths are not comparable: `cosineSimilarity` throws on different lengths.
